# Django E-Commerce Platform (Work in Progress 🚧)

This is an ongoing project to build a full-featured e-commerce platform using Django. Currently, I am focusing on building a rock-solid, secure foundation, starting with a completely custom user authentication and password management system.

## ✨ Completed Features (So Far)

* **Custom Authentication System:** Built from scratch without relying on third-party packages to ensure complete control over the user flow.
  * User Registration and Login/Logout functionality.
* **Secure Email Password Reset:** * Custom views to handle base64-encoded user IDs and secure token generation.
  * Professional HTML email templates sent via SMTP.
  * Security measures included: tokens automatically expire after 1 hour or immediately upon a password change to prevent replay attacks.
* **E-Commerce Foundation:** Basic routing and navigation bar set up for the future Home, Products, and Owner portals.

## 🗺️ Roadmap (Upcoming Features)

As development continues, I will be adding the following core e-commerce features:
- [ ] Product models, categories, and inventory management.
- [ ] User shopping cart functionality.
- [ ] Secure checkout and payment processing.
